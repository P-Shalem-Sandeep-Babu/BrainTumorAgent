  Key design decisions:
  - All hyperparameters centralized in src/utils/config.py
  - ViT layers are frozen progressively to prevent overfitting
  - RL environment is a single-step Gymnasium env (agent sees ViT features, picks a class)
  - PPO uses MlpPolicy on top of ViT embeddings
  - Streamlit app is multi-page (Dataset / Training / Prediction)
  - All modules have if __name__ == "__main__" blocks for quick testing





  How to use

  # 1. Place MRI images in data/raw/
  data/raw/glioma/*.jpg
  data/raw/meningioma/*.jpg
  data/raw/notumor/*.jpg
  data/raw/pituitary/*.jpg

  # 2. Split into train/val/test
  python prepare_data.py

  # 3. Visualize the dataset
  python visualize_dataset.py

  # 4. Run tests
  python -m pytest tests/test_preprocessing.py -v
